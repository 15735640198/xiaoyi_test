# HarmonyOS 设置脚本开发手册

> 本手册面向需要手动新增设置操作脚本的开发者。
> 基于三层架构：`hdc_utils.py`（底层工具）→ `settings_api.py`（业务 API）→ `xxx_manager.py`（CLI 脚本）
> 全文以"蓝牙设备连接"为示例，完整走一遍开发流程。

---

## 一、开发流程（5 步）

### 第 1 步：查知识库，确定参数

打开 `HarmonyOS设置功能知识库.md`，查找目标设置项的信息。

以"蓝牙设备连接"为例：

| 需要确认的参数 | 知识库章节 | 蓝牙设备连接的值 |
|--------------|----------|----------------|
| 入口文本 | 第三章 | `星闪和蓝牙` |
| 目标项文本 | 第三章 | `蓝牙`（开关）/ 设备名（设备列表中的 Text）|
| 滑动屏数 | 第八章 | `2` |
| 控件形态 | 第六章 | `toggle_row`（蓝牙开关）+ 设备列表（自定义交互）|
| 子页面 Toggle 文本 | 第四章 | 无（蓝牙开关在列表页直接操作）|
| 是否有安全认证门 | 第九章 | 无 |
| 是否触发弹窗 | 第七章 | 有（配对弹窗，含"配对"/"取消"按钮）|
| 页面加载时间 | 第十二章 | 3-5 秒（需等待设备扫描）|

**分析结论**：蓝牙设备连接属于复杂场景（形态 G）。蓝牙开关用 `toggle_row` 可以直接读写，但设备连接涉及滑动查找设备、点击设备行、处理配对弹窗、轮询连接状态，无法用通用 API 一行封装，需要用底层工具函数组合实现。

### 第 2 步：判断是否需要新增 API

先查 `settings_api.py` 和 `SKILL.md` 的 API 表格，看目标功能是否已有 API：

- **已有** → 直接跳到第 4 步写 CLI 脚本
- **没有** → 继续第 3 步添加 API

蓝牙设备的 API 已存在（`connect_bluetooth`、`disconnect_bluetooth`、`query_bluetooth_device`），但下面以"从头实现"的角度展示完整过程。

### 第 3 步：在 settings_api.py 中添加 API 函数

根据控件形态选择实现方式。下面先列出 6 种简单形态的 API 模板，再详细展示蓝牙设备连接的完整实现。

#### 简单形态 API 模板（通用 API 直接封装）

**形态 A：toggle_row**（如 WLAN、飞行模式、省电模式）— 列表页直接有 Toggle：

```python
def query_power_saving():
    return query_setting('电池', '省电模式', 'toggle_row', scroll=4)

def set_power_saving(desired):
    return toggle_setting('电池', '省电模式', 'toggle_row', desired, scroll=4)
```

**形态 B：button_card**（如勿扰模式）— 卡片内按钮文本表示状态：

```python
def query_dnd():
    return query_setting('情景模式', '免打扰', 'button_card', scroll=2)

def set_dnd(desired):
    return toggle_setting('情景模式', '免打扰', 'button_card', desired, scroll=2)
```

**形态 C：text_value + 子页面 Toggle**（如放大手势）— 需进子页面操作：

```python
def query_zoom_gesture():
    return query_setting('关怀和无障碍', '放大手势', 'text_value', scroll=4)

def set_zoom_gesture(desired):
    return toggle_setting('关怀和无障碍', '放大手势', 'text_value', desired,
                          scroll=4, third_level_toggle='放大手势')
```

**形态 D：nav_item → 子页面 Toggle**（如个人热点）— 进子页面查询：

```python
def query_personal_hotspot():
    return query_subpage_toggle('移动网络', '个人热点', scroll=1)
```

**形态 E：入口存在性判断**（如开发者模式）— 入口存在即开启：

```python
def query_developer_mode():
    return 'on' if check_entry_exists('系统', '开发者选项', scroll=4) else 'off'
```

**形态 F：slider_row**（如语速）— 读 `text`/`originalText` 属性：

```python
def query_speech_rate():
    layout = _navigate_to_speech_rate_page()
    return read_status(layout, '语速', 'slider_row')
```

#### 形态 G：复杂场景 — 蓝牙设备连接（完整实现）

蓝牙设备连接无法用通用 API 封装，需要用底层工具函数组合。实现思路：

```
连接流程: 打开蓝牙页面 → 确保蓝牙开启 → 滑动查找设备 → 点击设备 → 处理配对弹窗 → 轮询连接状态
查询流程: 打开蓝牙页面 → 检查蓝牙开关 → 滑动查找设备 → 查同行是否有"已连接"文本
断开流程: 打开蓝牙页面 → 滑动查找设备 → 点击设备 → 处理断开弹窗 → 轮询断开状态
```

**第 1 步：实现打开蓝牙页面的辅助函数**

```python
def _open_bluetooth_page():
    """打开蓝牙设置页面，等待设备列表加载"""
    restart_settings()
    layout = dump_layout()
    # 如果还没在蓝牙页面，点击"星闪和蓝牙"入口
    if not (find_by_text(layout, '已配对设备') or find_by_text(layout, '其他设备')):
        if not click_by_text(layout, '星闪和蓝牙'):
            for _ in range(3):
                swipe_up()
                layout = dump_layout()
                if click_by_text(layout, '星闪和蓝牙'):
                    break
            else:
                return None
    # 等待设备列表加载（蓝牙页面加载较慢，知识库第十二章: 3-5秒）
    for _ in range(10):
        layout = dump_layout()
        if find_by_text(layout, '已配对设备') or find_by_text(layout, '其他设备'):
            break
        time.sleep(1)
    time.sleep(5)  # 等待设备扫描完成
    return dump_layout()
```

**第 2 步：实现查询设备状态**

```python
def query_bluetooth_device(device_name):
    """
    查询蓝牙设备连接状态
    Returns: 'connected' | 'disconnected' | 'not_found' | 'bluetooth_off'
    """
    layout = _open_bluetooth_page()
    if not layout:
        return 'not_found'
    # 先检查蓝牙是否开启
    if read_status_toggle_row(layout, '蓝牙') != 'on':
        return 'bluetooth_off'
    # 滑动查找设备
    for _ in range(5):
        layout = dump_layout()
        comp = find_by_text(layout, device_name)
        if comp:
            center = parse_bounds(attr(comp[0], 'bounds'))
            if center:
                # 查同行是否有"已连接"文本
                for c in find_by_text(layout, '已连接'):
                    cc = parse_bounds(attr(c, 'bounds'))
                    if cc and abs(cc[1] - center[1]) < 80:
                        return 'connected'
                return 'disconnected'
        swipe_up(2.5)
        time.sleep(2)
    return 'not_found'
```

**第 3 步：实现连接设备**

```python
def connect_bluetooth(device_name):
    """
    连接蓝牙设备
    Returns: (success: bool, status: str)
    """
    layout = _open_bluetooth_page()
    if not layout:
        return False, 'not_found'
    # 确保蓝牙已开启
    if read_status_toggle_row(layout, '蓝牙') != 'on':
        toggle_operation(layout, '蓝牙', 'toggle_row', 'on')
        time.sleep(3)
    # 滑动查找设备
    for _ in range(5):
        layout = dump_layout()
        comp = find_by_text(layout, device_name)
        if comp:
            break
        swipe_up(2.5)
        time.sleep(2)
    else:
        return False, 'not_found'
    # 检查是否已连接
    center = parse_bounds(attr(comp[0], 'bounds'))
    for c in find_by_text(layout, '已连接'):
        cc = parse_bounds(attr(c, 'bounds'))
        if cc and abs(cc[1] - center[1]) < 80:
            return True, 'connected'
    # 点击设备
    click_by_text(layout, device_name, 1.0)
    # 处理配对弹窗（知识库第七章: 配对弹窗有"配对"/"取消"按钮）
    for _ in range(10):
        layout = dump_layout()
        btn = find_button(layout, '配对')  # find_button 排除"已配对设备"
        if btn:
            bc = parse_bounds(attr(btn[0], 'bounds'))
            if bc:
                click_at(bc[0], bc[1], 2.0)
                break
        time.sleep(1)
    # 轮询等待连接成功
    for _ in range(15):
        time.sleep(2)
        layout = dump_layout()
        for c in find_by_text(layout, '已连接'):
            cc = parse_bounds(attr(c, 'bounds'))
            if cc and center and abs(cc[1] - center[1]) < 80:
                return True, 'connected'
        # 处理可能出现的确认弹窗
        for btn_text in ['确定', '知道了']:
            btn = find_button(layout, btn_text)
            if btn:
                bc = parse_bounds(attr(btn[0], 'bounds'))
                if bc:
                    click_at(bc[0], bc[1], 2.0)
                    break
    return False, 'disconnected'
```

**第 4 步：实现断开设备**

```python
def disconnect_bluetooth(device_name):
    """
    断开蓝牙设备
    Returns: (success: bool, status: str)
    """
    layout = _open_bluetooth_page()
    if not layout:
        return False, 'not_found'
    if read_status_toggle_row(layout, '蓝牙') != 'on':
        return True, 'bluetooth_off'
    # 滑动查找设备
    for _ in range(5):
        layout = dump_layout()
        comp = find_by_text(layout, device_name)
        if comp:
            break
        swipe_up(2.5)
        time.sleep(2)
    else:
        return False, 'not_found'
    center = parse_bounds(attr(comp[0], 'bounds'))
    # 检查是否已断开
    connected = False
    for c in find_by_text(layout, '已连接'):
        cc = parse_bounds(attr(c, 'bounds'))
        if cc and abs(cc[1] - center[1]) < 80:
            connected = True
            break
    if not connected:
        return True, 'disconnected'
    # 点击设备 → 处理断开弹窗
    click_by_text(layout, device_name, 1.0)
    time.sleep(2)
    for btn_text in ['确定', '断开', '取消']:
        layout = dump_layout()
        btn = find_button(layout, btn_text)
        if btn:
            bc = parse_bounds(attr(btn[0], 'bounds'))
            if bc:
                click_at(bc[0], bc[1], 1.0)
                break
    # 轮询等待断开
    for _ in range(15):
        time.sleep(2)
        layout = dump_layout()
        still = False
        for c in find_by_text(layout, '已连接'):
            cc = parse_bounds(attr(c, 'bounds'))
            if cc and abs(cc[1] - center[1]) < 80:
                still = True
                break
        if not still:
            return True, 'disconnected'
    return False, 'connected'
```

### 第 4 步：编写 CLI 脚本

脚本是 API 的薄壳调度器，只做三件事：解析参数 → 调用 API → 输出结果。

蓝牙设备管理脚本需要三个模式（connect / disconnect / query）和设备名参数：

```python
#!/usr/bin/env python3
"""
HarmonyOS 蓝牙设备管理脚本（CLI 调度器）

API: settings_api.query_bluetooth_device / connect_bluetooth / disconnect_bluetooth

用法:
  python bluetooth_manager.py --mode query      --Bluetooth_name "设备名"
  python bluetooth_manager.py --mode connect    --Bluetooth_name "设备名"
  python bluetooth_manager.py --mode disconnect --Bluetooth_name "设备名"
"""

import argparse
from hdc_utils import find_hdc, check_device
from settings_api import (
    query_bluetooth_device,
    connect_bluetooth,
    disconnect_bluetooth,
)


def main():
    parser = argparse.ArgumentParser(description='HarmonyOS 蓝牙设备管理')
    parser.add_argument('--mode', required=True,
                        choices=['connect', 'disconnect', 'query'],
                        help='connect(连接) / disconnect(断开) / query(查询)')
    parser.add_argument('--Bluetooth_name', required=True,
                        help='蓝牙设备名称')
    args = parser.parse_args()

    print("=" * 50)
    print("  HarmonyOS 蓝牙设备管理")
    print(f"  模式: {args.mode}  设备: {args.Bluetooth_name}")
    print("=" * 50)

    find_hdc()
    device = check_device()
    print(f"  设备: {device}")

    if args.mode == 'query':
        status = query_bluetooth_device(args.Bluetooth_name)
        print(f"\n  >>> '{args.Bluetooth_name}': {status} <<<")

    elif args.mode == 'connect':
        success, status = connect_bluetooth(args.Bluetooth_name)
        if success:
            print(f"\n  >>> '{args.Bluetooth_name}' 连接成功 <<<")
        else:
            print(f"\n  >>> '{args.Bluetooth_name}' 连接失败 ({status}) <<<")

    elif args.mode == 'disconnect':
        success, status = disconnect_bluetooth(args.Bluetooth_name)
        if success:
            print(f"\n  >>> '{args.Bluetooth_name}' 断开成功 <<<")
        else:
            print(f"\n  >>> '{args.Bluetooth_name}' 断开失败 ({status}) <<<")


if __name__ == '__main__':
    main()
```

#### 命名规范

| 脚本类型 | 命名 | 示例 |
|---------|------|------|
| 纯查询 | `query_<功能>_state.py` | `query_zoom_gesture_state.py` |
| 开关操作 | `<功能>_manager.py` | `bluetooth_manager.py` |

## 二、公共方法参考

### 2.1 hdc_utils.py — 底层工具

#### 常量

| 常量 | 说明 |
|------|------|
| `SETTINGS_BUNDLE` | 设置应用包名 `com.huawei.hmos.settings` |
| `SETTINGS_ABILITY` | 设置主 Ability `com.huawei.hmos.settings.MainAbility` |
| `HDC_COMMON_PATHS` | hdc 可执行文件搜索路径列表 |
| `NAV_WAIT` | 导航后默认等待时间 2.5s |
| `DUMP_WAIT` | dumpLayout 后等待时间 1.0s |
| `HDC` | hdc 路径，`find_hdc()` 后赋值 |

#### 设备连接

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `find_hdc()` | 无 | `str` | 查找 hdc 路径，PATH 中有则用 `hdc`，否则搜索 SDK 目录 |
| `check_device()` | 无 | `str` | 检查设备连接，返回设备 ID，无设备则退出 |
| `run_cmd(cmd, timeout)` | cmd: list, timeout: int | `str` | 执行命令，返回 stdout+stderr |
| `hdc_shell(*args, timeout)` | args: 命令参数 | `str` | 执行 `hdc shell <args>` |

#### 布局获取

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `dump_layout()` | 无 | `dict` | uitest dumpLayout → 接收 JSON → 返回 dict |

#### 属性读取

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `attr(comp, key, default)` | comp: dict, key: str | `str` | 读组件属性，从 `attributes` 字典取值 |
| `get_text(comp)` | comp: dict | `str` | 读文本，优先 `text`，其次 `description` |

**注意**：属性在 `node["attributes"]["text"]`，不是 `node["text"]`。

#### 组件搜索

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `find_components(node, predicate)` | node: dict, predicate: lambda | `list` | 递归搜索所有满足条件的组件 |
| `find_by_text(node, text)` | text: str | `list` | 子串匹配查找文本组件 |
| `find_by_text_nearest(node, text)` | text: str | `list` | 同上，但按文本长度差排序，最接近的优先 |
| `find_button(node, text)` | text: str | `list` | 查找按钮，排除含"设备"的长文本，长度 ≤ 5 |
| `find_toggles(node)` | 无 | `list` | 查找所有 Toggle/Switch |
| `find_sliders(node)` | 无 | `list` | 查找所有 Slider |
| `find_buttons(node)` | 无 | `list` | 查找所有 Button |
| `find_menu_items(node)` | 无 | `list` | 查找所有 MenuItem（选择器选项） |

#### 坐标解析

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `parse_bounds(bounds)` | bounds: str `"[l,t][r,b]"` | `(cx, cy)` 或 `None` | 解析为中心坐标 |
| `parse_full_bounds(bounds)` | bounds: str | `(l, t, r, b)` 或 `None` | 解析为完整边界 |

#### UI 操作

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `click_at(x, y, wait)` | x, y: int, wait: float | 无 | 点击坐标，wait 后继续 |
| `click_by_text(layout, text, wait)` | layout: dict, text: str | `bool` | 点击文本组件，自动找可点击父级 |
| `swipe_up(wait)` | wait: float | 无 | 向上滑动 |
| `swipe_down(wait)` | wait: float | 无 | 向下滑动 |
| `go_back(wait)` | wait: float | 无 | 按返回键 |

#### 状态读取

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `read_toggle_state(comp)` | comp: dict | `'on'`/`'off'`/`'unknown'` | 读 Toggle 的 checked 属性 |
| `read_status_toggle_row(layout, target)` | target: str | `'on'`/`'off'`/`'unknown'`/`None` | 找目标附近的 Toggle 读状态 |
| `read_status_button_card(layout, target)` | target: str | 同上 | 找目标附近的 Button 读状态 |
| `read_status_text_value(layout, target, on, off)` | target, on, off: str | 同上 | 找目标右侧同行文本读状态 |
| `read_status_slider(layout, target)` | target: str | `str`/`'unknown'`/`None` | 读 Slider 的 text/originalText |
| `read_status(layout, target, form, on, off)` | form: str | 同上 | 按形态自动分发到上面 4 个函数 |

#### 开关操作

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|

#### 导航

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `restart_settings()` | 无 | 无 | force-stop + 重新启动设置应用 |

| `find_target_with_scroll(layout, target, form, scroll, on, off)` | 同 read_status | `(dict, status)` | 滑动查找目标并读状态 |

### 2.2 settings_api.py — 业务 API

#### 通用 API（适用于任何设置项）

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `query_setting(entry, target, form, scroll, on, off)` | 见下 | `'on'`/`'off'`/`'unknown'`/`None` | 查询任意设置项 |
| `toggle_setting(entry, target, form, desired, scroll, toggle_text, on, off)` | 见下 | `(bool, str)` | 切换任意设置项，返回(成功, 新状态) |
| `check_entry_exists(entry, target, scroll)` | entry, target: str, scroll: int | `bool` | 检查入口是否存在 |
| `query_subpage_toggle(entry, target, scroll)` | entry, target: str, scroll: int | `'on'`/`'off'`/`'unknown'`/`None` | 进入子页面查 Toggle |

通用 API 参数说明：

```
entry            设置首页入口文本（如 '星闪和蓝牙'）
target           目标设置项文本（如 '蓝牙'）
form             控件形态（'toggle_row'/'button_card'/'text_value'/'slider_row'/'nav_item'）
scroll           滑动屏数（知识库第八章）
desired          目标状态（'on' 或 'off'）
toggle_text      子页面 Toggle 文本（text_value 开关操作时需要）
on / off         状态文本（text_value 形态，默认 '已开启'/'已关闭'）
```

#### 专用 API（已实现，直接调用）

| 设置项 | 查询函数 | 开关函数 | 形态 |
|--------|---------|---------|------|
| 勿扰模式 | `query_dnd()` | `set_dnd(desired)` | button_card |
| 放大手势 | `query_zoom_gesture()` | `set_zoom_gesture(desired)` | text_value |
| 开发者模式 | `query_developer_mode()` | — | 入口存在性 |

| 返回类型 | 说明 | 示例 |

## 四、关键规则（避坑）

1. **Slider 的值在 `text`/`originalText` 属性中**，不是 `value`
2. **选择器选项是 `MenuItem` 类型**，不是 `Text` — 点击即选中，自动关闭
3. **Text 组件通常 `clickable=false`** — `click_by_text()` 会自动找可点击父级
4. **`find_by_text` 是子串匹配** — 用 `find_button()` 或 `find_by_text_nearest()` 避免误匹配（如搜"配对"会匹配到"已配对设备"）
5. **toggle_row 和 button_card 操作不触发弹窗** — 直接验证状态
6. **text_value 开关需要 3 步**：列表页 → 点击项 → 子页面 Toggle → 返回 → 验证
7. **每次 API 调用都会 restart_settings()** — 无状态，脚本间互不影响
8. **属性是嵌套的**：`node["attributes"]["text"]`，不是 `node["text"]`
9. **API 函数不包含 print** — 只返回结果，打印交给 CLI 脚本
10. **蓝牙页面加载慢（3-5 秒）** — 需要额外等待设备列表出现后再操作
11. **配对弹窗用 `find_button()` 不用 `find_by_text()`** — 避免匹配到"已配对设备"标题
